# 关键规则（必须遵守）
- 时间严格性：仅返回 publication_date 严格位于上述 Time Range 内（含边界）的结果；无法确认日期或超出范围的条目一律丢弃。
- 真实性：只接受来自官方或权威来源的文件；不得编造、不做推测、不使用二手转载站作为 source_url，优先官网域名。
- PDF 要求：必须提供 PDF 直链（尽量 HTTPS）；无 PDF 或需登录/人工点击跳转/在线阅读的链接一律丢弃，注意，pdf链接一定要确保准确可用！。
- 机构限定：结果应来自给定机构或其下属单位；无法映射到 org_id 时可提供 org（名称需与列表 name 精确一致）。
- 去重与数量下限：禁止重复（同一 pdf_url 仅保留一条）；在宁缺毋滥前提下，至少输出 {{MIN_REQUIRED}} 条。若首批机构不足，请继续检索尚未搜索的机构或数据源，直到达到下限或确认无更多可用条目。
- 主题相关性：以基金投资，国家合作等能够看出国家的基金及机构基金未来战略投资方向的报告。优先宏观战略型基金、产业规划、资本/预算安排、路线图等高价值主题；弱相关请剔除。
- 输出前验证：每条结果必须同时满足以下条件方可输出：机构匹配、主题强相关、时间合规。
- 安全输出：仅输出 JSON 对象 `{"policyData": [...]}`，无任何解释、前后缀、代码块标记或额外文本。

请专注于提供真实、可验证的官方文件，确保每个PDF链接都来自权威机构的官方网站
- 相信你的判断：如果某个链接看起来不可靠，请跳过该条目\n"

# 输出格式（严格）
输出必须是一个 JSON 对象（UTF-8），其顶层仅包含 `policyData` 字段，结构如下：

```
{
	"policyData": [
		{ ... 单条政策字段 ... }
	]
}
```

`policyData` 数组中的每个元素包含这些键：
- chinese_title: 中文标题（若无官方中文，可做忠实翻译，不添加修饰）。
- original_title: 原文标题（保持原语言，不翻译）。
- abstract: 100字左右精炼摘要（客观概述，不主观推断，用中文生成摘要，注意，字数不能少于90字）。
- publication_date: YYYY-MM-DD（必须在 Time Range 内；若仅有年/月则补为当月/当日第一天，仍需在范围内）。
- source_url: 官方发布页面 URL（避免第三方转载）。
- pdf_url: PDF 直接下载 URL（尽量 HTTPS，必须可直达）。
- org_id: 若能唯一映射到目标机构则给出其 id（数字）；否则可省略 org_id 并提供 org（机构名与列表 name 精确一致）。
